# selectel_vpc_router_v2

Creates and manages a cloud router using the v2 public API. For more information about cloud routers, see the [official Selectel documentation](https://docs.selectel.ru/en/cloud-servers/cloud-networks/cloud-routers/).

If you are upgrading from a version earlier than 9.0.0, follow the [upgrade guide](https://registry.terraform.io/providers/selectel/selectel/latest/docs/guides/upgrading_to_version_9) to migrate your resources from the OpenStack provider.

## Example Usage

```terraform
# Router with default settings
resource "selectel_vpc_router_v2" "router_1" {
  project_id = selectel_vpc_project_v2.project_1.id
  region     = "ru-6"
}
```

```terraform
# Router with high availability
resource "selectel_vpc_router_v2" "router_1" {
  project_id = selectel_vpc_project_v2.project_1.id
  region     = "ru-6"
  ha         = true
}
```

## Schema

### Required

- `project_id` (String) Unique identifier of the associated project, for example, `a07abc12310546f1b9291ab3013a7d75`. Retrieved from the [selectel_vpc_project_v2](https://registry.terraform.io/providers/selectel/selectel/latest/docs/resources/vpc_project_v2) resource. Learn more about [Projects](https://docs.selectel.ru/en/control-panel-actions/projects/about-projects/). Changing this creates a new router.
- `region` (String) Pool where the router is located, for example, `ru-6`. Learn more about available pools in [Product availability by location](https://docs.selectel.ru/en/infrastructure/product-availability-by-location/). Changing this creates a new router.

### Optional

- `admin_state_up` (Boolean) Specifies if the router is administratively up. The default value is `true`.
- `availability_zone_hints` (List of String) Pool segments requested for allocating the router. Learn more about available pools in [Product availability by location](https://docs.selectel.ru/en/infrastructure/product-availability-by-location/). Changing this creates a new router.
- `description` (String) Description of the router.
- `enable_snat` (Boolean) Specifies if source NAT is enabled on the gateway. Requires `external_network_id`.
- `external_network_id` (String) Unique identifier of the external network the gateway is attached to. Retrieved from the [selectel_vpc_network_v2](https://registry.terraform.io/providers/selectel/selectel/latest/docs/data-sources/vpc_network_v2) data source with `external = true` filter.
- `ha` (Boolean) Specifies if the router runs in high availability mode. Changing it on an existing router disables the router for the time of the change, so traffic through it is interrupted. If not specified, high availability is disabled.
- `name` (String) Name of the router.
- `tags` (Set of String) Tags of the router.
- `timeouts` (Block, Optional) (see [below for nested schema](#nestedblock--timeouts))

### Read-Only

- `all_tags` (Set of String) All tags of the router.
- `availability_zones` (List of String) Pool segments where the router is actually allocated.
- `blocked` (Boolean) Specifies if the router is administratively blocked.
- `external_fixed_ip` (List of Object) Gateway addresses of the router. (see [below for nested schema](#nestedatt--external_fixed_ip))
- `id` (String) Unique identifier of the router.
- `status` (String) Status of the router.

## Import

### In Terraform 1.12.0 and later

Use the [`import` block](https://developer.hashicorp.com/terraform/language/import) with the `identity` attribute:

```terraform
import {
  to = selectel_vpc_router_v2.router_1
  identity = {
    id         = "<id>"
    project_id = "<project_id>"
    region     = "<region>"
  }
}
```

### Identity Schema

#### Required

- `id` (String) Unique identifier of the router, for example, `b311ce58-2658-46b5-b733-7a0f418703f2`. To get the router ID, in the [Control panel](https://my.selectel.ru/vpc/), go to **Products** ⟶ **Cloud Servers** ⟶ **Network** ⟶ the **Cloud routers** tab ⟶ copy the ID in the card of the required router.
- `project_id` (String) Unique identifier of the associated project, for example, `a07abc12310546f1b9291ab3013a7d75`. To get the project ID, in the [Control panel](https://my.selectel.ru/vpc/), go to **Products** ⟶ **Cloud Servers** ⟶ project name ⟶ copy the ID of the required project. Learn more about [Projects](https://docs.selectel.ru/en/control-panel-actions/projects/about-projects/).
- `region` (String) Pool where the router is located, for example, `ru-6`. To get the pool, in the [Control panel](https://my.selectel.ru/vpc/), go to **Products** ⟶ **Cloud Servers** ⟶ **Network** ⟶ the **Cloud routers** tab. The pool is in the card of the router, under the router name. Learn more about available pools in [Product availability by location](https://docs.selectel.ru/en/infrastructure/product-availability-by-location/).

### All versions

Use the [`terraform import` command](https://developer.hashicorp.com/terraform/cli/commands/import):

```shell
export OS_DOMAIN_NAME=<domain_name>
export OS_USERNAME=<username>
export OS_PASSWORD=<password>
export INFRA_PROJECT_ID=<project_id>
export INFRA_REGION=<region>

terraform import selectel_vpc_router_v2.router_1 <id>
```

`<domain_name>`, `<username>`, and `<password>` are the arguments of the [provider configuration](https://registry.terraform.io/providers/selectel/selectel/latest/docs).
Other identity attributes are described above in the import or resource sections.
