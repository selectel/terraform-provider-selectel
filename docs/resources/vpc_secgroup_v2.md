# selectel_vpc_secgroup_v2

Creates and manages a security group using public API v2. For more information about security groups, see the [official Selectel documentation](https://docs.selectel.ru/en/cloud-servers/security-groups/).

If you are upgrading from a version earlier than 9.0.0, follow the [upgrade guide](https://registry.terraform.io/providers/selectel/selectel/latest/docs/guides/upgrading_to_version_9) to migrate your resources from the OpenStack provider.

## Example Usage

```terraform
# Creating a security group
resource "selectel_vpc_secgroup_v2" "secgroup_1" {
  project_id = selectel_vpc_project_v2.project_1.id
  region     = "ru-6"
  name       = "secgroup-1"
}

# Starting from an empty group, without the egress rules the API adds
resource "selectel_vpc_secgroup_v2" "secgroup_2" {
  project_id           = selectel_vpc_project_v2.project_1.id
  region               = "ru-6"
  name                 = "secgroup-2"
  delete_default_rules = true
}
```

## Schema

### Required

- `name` (String) Name of the security group.
- `project_id` (String) Unique identifier of the associated project, for example, `a07abc12310546f1b9291ab3013a7d75`. Retrieved from the [selectel_vpc_project_v2](https://registry.terraform.io/providers/selectel/selectel/latest/docs/resources/vpc_project_v2) resource. Learn more about [Projects](https://docs.selectel.ru/en/control-panel-actions/projects/about-projects/). Changing this creates a new security group.
- `region` (String) Pool where the security group is located, for example, `ru-6`. Learn more about available pools in [Product availability by location](https://docs.selectel.ru/en/infrastructure/product-availability-by-location/). Changing this creates a new security group.

### Optional

- `delete_default_rules` (Boolean) Specifies whether to delete the default egress rules. Default value is `false`. Changing this creates a new security group. The default value is `false`.
- `description` (String) Description of the security group.
- `stateful` (Boolean) Specifies if the security group is stateful. Default value is `false`.
- `tags` (Set of String) Tags of the security group.
- `timeouts` (Block, Optional) (see [below for nested schema](#nestedblock--timeouts))

### Read-Only

- `all_tags` (Set of String) All tags of the security group.
- `id` (String) Unique identifier of the security group.
- `security_group_rules` (List of String) Unique identifiers of rules contained in the security group.
- `shared` (Boolean) Specifies if another project has been granted access to this group.
