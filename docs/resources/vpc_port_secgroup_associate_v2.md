# selectel_vpc_port_secgroup_associate_v2

Creates and manages the association between security groups and an existing port using public API v2. For more information about security groups, see the [official Selectel documentation](https://docs.selectel.ru/en/cloud-servers/security-groups/).

The resource addresses the port by identifier, never creates or deletes it, and does not manage any of its other attributes. Do not manage the same port with both this resource and the `security_group_ids` argument of `selectel_vpc_port_v2`.

If you are upgrading from a version earlier than 9.0.0, follow the [upgrade guide](https://registry.terraform.io/providers/selectel/selectel/latest/docs/guides/upgrading_to_version_9) to migrate your resources from the OpenStack provider.

## Example Usage

```terraform
# Security group added to the existing groups of the port
resource "selectel_vpc_port_secgroup_associate_v2" "associate_1" {
  project_id         = selectel_vpc_project_v2.project_1.id
  region             = "ru-6"
  port_id            = data.selectel_vpc_port_v2.port_1.id
  security_group_ids = [selectel_vpc_secgroup_v2.secgroup_1.id]
}
```

```terraform
# Security groups that replace the existing groups of the port
resource "selectel_vpc_port_secgroup_associate_v2" "associate_2" {
  project_id         = selectel_vpc_project_v2.project_1.id
  region             = "ru-6"
  port_id            = data.selectel_vpc_port_v2.port_1.id
  security_group_ids = [selectel_vpc_secgroup_v2.secgroup_1.id]
  enforce            = true
}
```

## Schema

### Required

- `port_id` (String) Unique identifier of the port. Retrieved from the [selectel_vpc_port_v2](https://registry.terraform.io/providers/selectel/selectel/latest/docs/resources/vpc_port_v2) resource. Changing this creates a new port security group association.
- `project_id` (String) Unique identifier of the associated project, for example, `a07abc12310546f1b9291ab3013a7d75`. Retrieved from the [selectel_vpc_project_v2](https://registry.terraform.io/providers/selectel/selectel/latest/docs/resources/vpc_project_v2) resource. Learn more about [Projects](https://docs.selectel.ru/en/control-panel-actions/projects/about-projects/). Changing this creates a new port security group association.
- `region` (String) Pool where the port security group association is located, for example, `ru-6`. Learn more about available pools in [Product availability by location](https://docs.selectel.ru/en/infrastructure/product-availability-by-location/). Changing this creates a new port security group association.
- `security_group_ids` (Set of String) Unique identifiers of the security groups this resource manages on the port. Retrieved from the [selectel_vpc_secgroup_v2](https://registry.terraform.io/providers/selectel/selectel/latest/docs/resources/vpc_secgroup_v2) resource.

### Optional

- `enforce` (Boolean) Specifies if `security_group_ids` replaces the port's list of security groups or is appended to it. If `false`, deleting the resource removes from the port only the groups listed in `security_group_ids`. If `true`, deleting the resource removes all security groups from the port. The default value is `false`.

### Read-Only

- `all_security_group_ids` (Set of String) All unique identifiers of security groups of the port.
- `id` (String) Unique identifier of the port, for example, `1a2b3c4d-5e6f-7081-92a3-b4c5d6e7f809`.
