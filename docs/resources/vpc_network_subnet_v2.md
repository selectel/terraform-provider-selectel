# selectel_vpc_network_subnet_v2

Creates and manages a subnet of a private network using public API v2. For more information about private networks and subnets, see the [official Selectel documentation](https://docs.selectel.ru/en/cloud-servers/cloud-networks/private-networks-and-subnets/).

If you are upgrading from a version earlier than 9.0.0, follow the [upgrade guide](https://registry.terraform.io/providers/selectel/selectel/latest/docs/guides/upgrading_to_version_9) to migrate your resources from the OpenStack provider.

## Example Usage

```terraform
resource "selectel_vpc_network_subnet_v2" "subnet_1" {
  project_id = selectel_vpc_project_v2.project_1.id
  region     = "ru-6"
  network_id = selectel_vpc_network_v2.network_1.id
  cidr       = "192.168.199.0/24"
}
```

### Required

Learn more about [Projects](https://docs.selectel.ru/en/control-panel-actions/projects/about-projects/). Changing this creates a new subnet.
- `region` (String) Pool where the subnet is located, for example, `ru-6`. Learn more about available pools in [Product availability by location](https://docs.selectel.ru/en/infrastructure/product-availability-by-location/). Changing this creates a new subnet.

### Optional

- `allocation_pool` (Block Set) Allocation pools of the subnet. (see [below for nested schema](#nestedblock--allocation_pool))
- `description` (String) Description of the subnet.
- `dns_nameservers` (List of String) DNS nameservers of the subnet, for example, `188.93.16.19`.
- `enable_dhcp` (Boolean) Specifies if DHCP is enabled for the subnet. The default value is `true`.
- `gateway_ip` (String) Gateway of the subnet, for example, `192.168.199.1`. Default value is the first address of the subnet. Conflicts with `no_gateway`.
- `ip_version` (Number) Internet protocol version. Available versions are `4` or `6`. Changing this creates a new subnet. The default value is `4`.
- `ipv6_address_mode` (String) IPv6 address assignment mode. Requires `ip_version` is `6`. Available modes are `slaac`, `dhcpv6-stateful`, or `dhcpv6-stateless`. Changing this creates a new subnet.
- `ipv6_ra_mode` (String) IPv6 router advertisement mode. Requires `ip_version` to be `6`. Available modes are `slaac`, `dhcpv6-stateful`, or `dhcpv6-stateless`. Changing this creates a new subnet.
- `name` (String) Name of the subnet.
- `no_gateway` (Boolean) Specifies whether to create the subnet without a gateway. Conflicts with `gateway_ip`. The default value is `false`.
- `tags` (Set of String) Tags of the subnet.
- `timeouts` (Block, Optional) (see [below for nested schema](#nestedblock--timeouts))
