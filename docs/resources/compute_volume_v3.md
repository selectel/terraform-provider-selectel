# selectel_compute_volume_v3

Creates and manages a network volume in Cloud Servers using the v3 public API. The volume size can only increase. Detach the volume before deletion. For more information about network volumes, see the [official Selectel documentation](https://docs.selectel.ru/en/cloud-servers/volumes/about-network-volumes/).

To create a volume from an existing source, set at most one of `snapshot_id`, `source_volume_id`, `image_id`, or `backup_id`.

## Example Usage

### Create an empty network volume

```terraform
resource "selectel_compute_volume_v3" "volume_1" {
  project_id = selectel_vpc_project_v2.project_1.id
  region     = "ru-6"
  size       = 10
}
```

### Create an SSD Fast v2 network volume with custom IOPS

```terraform
resource "selectel_compute_volume_v3" "volume_1" {
  project_id        = selectel_vpc_project_v2.project_1.id
  region            = "ru-6"
  size              = 10
  availability_zone = "ru-6a"
  volume_type       = data.selectel_compute_volume_type_v3.volume_type_1.name

  metadata = {
    total_iops_sec = "30000"
  }
}
```

### Create a network volume from a snapshot

```terraform
resource "selectel_compute_volume_v3" "volume_1" {
  project_id        = selectel_vpc_project_v2.project_1.id
  region            = "ru-6"
  size              = 20
  availability_zone = "ru-6a"
  volume_type       = data.selectel_compute_volume_type_v3.volume_type_1.name
  snapshot_id       = data.selectel_compute_snapshot_v3.snapshot_1.id
}
```

## Schema

### Required

- `project_id` (String) Unique identifier of the associated project, for example, `a07abc12310546f1b9291ab3013a7d75`. The value cannot be empty or start or end with whitespace. You can retrieve the project ID from the [selectel_vpc_project_v2](https://registry.terraform.io/providers/selectel/selectel/latest/docs/resources/vpc_project_v2) resource. Learn more about [Projects](https://docs.selectel.ru/en/control-panel-actions/projects/about-projects/). Changing this creates a new network volume.
- `region` (String) Pool where the network volume is located, for example, `ru-6`. The value cannot be empty or start or end with whitespace. Learn more about available pools in [Product availability by location](https://docs.selectel.ru/en/infrastructure/product-availability-by-location/#network-volumes). Changing this creates a new network volume.

### Optional

- `availability_zone` (String) Pool segment, for example, `ru-6a`. The value cannot be empty or start or end with whitespace. The API selects a segment when omitted. Learn more about available pool segments in [Product availability by location](https://docs.selectel.ru/en/infrastructure/product-availability-by-location/#network-volumes). Changing this creates a new network volume.
- `backup_id` (String) Unique identifier of the backup to restore. The format is a lowercase UUID. This argument requires `name`. This argument conflicts with `snapshot_id`, `source_volume_id`, and `image_id`. If `size` is omitted, the API uses the backup size. Import does not restore this argument. To get the backup ID, use the [OpenStack CLI](https://docs.selectel.ru/en/cloud-servers/tools/openstack-cli/) command `openstack volume backup list` and copy the `ID` field. Changing this creates a new network volume.
- `description` (String) Description of the network volume. The maximum length is `255` characters. The value cannot start or end with whitespace. The default value is an empty string.
- `enable_online_resize` (Boolean) Specifies if Terraform can increase the size of a network volume that is attached to a cloud server. The provider does not expand partitions or file systems. The default value is `false`. For more information about extending attached volumes, see the [official OpenStack documentation](https://docs.openstack.org/cinder/latest/cli/cli-manage-volumes.html#extend-attached-volume).
- `image_id` (String) UUID, name, or API URL of the source image. The value cannot be empty or start or end with whitespace. This argument conflicts with `snapshot_id`, `source_volume_id`, and `backup_id`. This argument requires `size`. Import does not restore this argument. Learn more about the [openstack_images_image_v2](https://registry.terraform.io/providers/terraform-provider-openstack/openstack/latest/docs/resources/images_image_v2) resource in the official OpenStack documentation. Changing this creates a new network volume.
- `metadata` (Map of String) Key-value pairs of the network volume. Each key and value is limited to 255 characters. Keys can contain ASCII letters, digits, underscores, colons, periods, spaces, slashes, and hyphens. Metadata added by the API is available in `service_metadata`. Import does not restore this argument. Special keys:
  - `total_iops_sec` — custom IOPS as a decimal string, for volume types that support it. You can change the value but cannot remove it. Learn more about available values in [network volume limits](https://docs.selectel.ru/en/cloud-servers/volumes/about-network-volumes/#network-volume-limits).
  - `total_bytes_sec` — managed by the API and cannot be set.
  - `selectel_tf_create_token` — reserved by the provider and cannot be set.
- `name` (String) Name of the network volume. The maximum length is `255` characters. The value cannot start or end with whitespace. With `backup_id`, this argument is required and cannot be empty. The default value is an empty string.
- `size` (Number) Size of the network volume in GB. The available range is from `1` to `2147483647`. This argument is required unless `snapshot_id`, `source_volume_id`, or `backup_id` is set. It is also required with `image_id`. Only increases are supported. To increase the size of a network volume attached to a cloud server, set `enable_online_resize` to `true`. Learn more about [network volume limits](https://docs.selectel.ru/en/cloud-servers/volumes/about-network-volumes/#network-volume-limits).
- `snapshot_id` (String) Unique identifier of the source snapshot. The format is a lowercase UUID. This argument requires `volume_type`. You can retrieve the snapshot ID with the [selectel_compute_snapshot_v3](https://registry.terraform.io/providers/selectel/selectel/latest/docs/data-sources/compute_snapshot_v3) data source. Changing this creates a new network volume.
- `source_volume_id` (String) Unique identifier of the source network volume. The format is a lowercase UUID. This argument conflicts with `snapshot_id`, `image_id`, and `backup_id`. If `size` is omitted, the API uses the source volume size. Import restores this argument. You can retrieve the source volume ID from the [selectel_compute_volume_v3](https://registry.terraform.io/providers/selectel/selectel/latest/docs/resources/compute_volume_v3) resource. Changing this creates a new network volume.

- `volume_type` (String) Name or UUID of the volume type. The value cannot be empty or start or end with whitespace. The name format is `<volume_type>.<availability_zone>`, for example, `fast2.ru-6a` for SSD Fast v2 in the `ru-6a` pool segment. This argument is required with `snapshot_id`. In other cases, the API chooses a type when omitted. You can retrieve the volume type name with the [selectel_compute_volume_type_v3](https://registry.terraform.io/providers/selectel/selectel/latest/docs/data-sources/compute_volume_type_v3) data source. ## Import

### In Terraform 1.5.0 and later

Use the [`import` block](https://developer.hashicorp.com/terraform/language/import) with the `id` attribute:

```terraform
# Set the project and pool in the provider configuration or the
# INFRA_PROJECT_ID and INFRA_REGION environment variables.
# Leave `image_id` and `backup_id` unset in the resource configuration after import.
# These fields are not restored. Setting either plans replacement of the volume.
# Set `volume_type` to the volume type name or leave it unset.
# A volume type UUID plans replacement of the volume.
import {
  to = selectel_compute_volume_v3.volume_1
  id = "<volume_uuid>"
}
```

### All versions

Use the [`terraform import` command](https://developer.hashicorp.com/terraform/cli/commands/import):

```shell
# Import the existing network volume by its UUID.
# Leave `image_id` and `backup_id` unset in the resource configuration after import.
# These fields are not restored. Setting either plans replacement of the volume.
# Set `volume_type` to the volume type name or leave it unset.
# A volume type UUID plans replacement of the volume.
# Set the project and pool containing the volume.
export OS_DOMAIN_NAME=<domain_name>
export OS_USERNAME=<username>
export OS_PASSWORD=<password>
export INFRA_PROJECT_ID=<project_id>
export INFRA_REGION=<region>

terraform import selectel_compute_volume_v3.volume_1 <volume_uuid>
```

`<domain_name>`, `<username>`, and `<password>` are the arguments of the [provider configuration](https://registry.terraform.io/providers/selectel/selectel/latest/docs).
