# selectel_compute_image_access_accept_v2

Creates and manages the acceptance of access to a shared image in Cloud Servers using the v2 public API. Access works only within a pool: the receiving project can use the image only in the pool where the image is located. Changing the status requires a role that allows managing image access in the receiving project. For more information about access to images and the roles, see the [official Selectel documentation](https://docs.selectel.ru/en/cloud-servers/images/manage-access/).

The resource is managed in the project that received access. The image owner grants access with the [selectel_compute_image_access_v2](https://registry.terraform.io/providers/selectel/selectel/latest/docs/resources/compute_image_access_v2) resource. Destroying the resource rejects the access instead of removing it: only the image owner can remove access. If the image owner changes the image visibility from `shared`, the access is hidden from the receiving project: Terraform removes the resource from the state and creates it again after the image is shared again.

## Example Usage

### Accept access to a shared image

```terraform
resource "selectel_compute_image_access_accept_v2" "image_access_accept_1" {
  project_id = selectel_vpc_project_v2.project_2.id
  region     = "ru-6"
  image_id   = selectel_compute_image_access_v2.image_access_1.image_id
  status     = "accepted"
}
```

## Schema

### Required

- `image_id` (String) Unique identifier of the shared image. The format is a lowercase UUID. You can retrieve the image ID from the [selectel_compute_image_access_v2](https://registry.terraform.io/providers/selectel/selectel/latest/docs/resources/compute_image_access_v2) resource. You can retrieve the image ID with the [selectel_compute_image_v2](https://registry.terraform.io/providers/selectel/selectel/latest/docs/data-sources/compute_image_v2) data source. To find an image shared with the project, set `visibility = "shared"` and `member_status = "all"` in the data source. Changing this creates a new image access acceptance.
- `project_id` (String) Unique identifier of the associated project, for example, `a07abc12310546f1b9291ab3013a7d75`. The value cannot be empty or start or end with whitespace. You can retrieve the project ID from the [selectel_vpc_project_v2](https://registry.terraform.io/providers/selectel/selectel/latest/docs/resources/vpc_project_v2) resource. Learn more about [Projects](https://docs.selectel.ru/en/control-panel-actions/projects/about-projects/). Changing this creates a new image access acceptance.
- `region` (String) Pool where the image access acceptance is located, for example, `ru-6`. The value cannot be empty or start or end with whitespace. Learn more about available pools in [Product availability by location](https://docs.selectel.ru/en/infrastructure/product-availability-by-location/). Changing this creates a new image access acceptance.
- `status` (String) Status of the access. Available values are `accepted`, `rejected`, and `pending`. With `accepted`, the image appears in the default image list of the project.

### Optional

- `member_id` (String) Unique identifier of the project that received access. The value cannot be empty or start or end with whitespace. A project can change only its own access, so the value must match `project_id`. If omitted, the provider uses `project_id`. Changing this creates a new image access acceptance.

### Read-Only

- `created_at` (String) Time when the access was granted in the RFC 3339 format.
- `id` (String) Unique identifier of the image access in the `<image_id>/<member_id>` format.
- `updated_at` (String) Time when the access was last updated in the RFC 3339 format.

## Import

### In Terraform 1.5.0 and later

Use the [`import` block](https://developer.hashicorp.com/terraform/language/import) with the `id` attribute:

```terraform
# Set the pool in the provider configuration or the INFRA_REGION environment variable.
# With `<image_uuid>` alone, Terraform takes the project from the provider configuration
# or the INFRA_PROJECT_ID environment variable.
import {
  to = selectel_compute_image_access_accept_v2.image_access_accept_1
  id = "<image_uuid>/<project_id>"
}
```

### All versions

Use the [`terraform import` command](https://developer.hashicorp.com/terraform/cli/commands/import):

```shell
# Import the access by the image UUID and the ID of the project that received access.
# With `<image_uuid>` alone, Terraform takes the project from INFRA_PROJECT_ID.
# Set the pool of the image.
export OS_DOMAIN_NAME=<domain_name>
export OS_USERNAME=<username>
export OS_PASSWORD=<password>
export INFRA_REGION=<region>

terraform import selectel_compute_image_access_accept_v2.image_access_accept_1 <image_uuid>/<project_id>
```

`<domain_name>`, `<username>`, and `<password>` are the arguments of the [provider configuration](https://registry.terraform.io/providers/selectel/selectel/latest/docs).
