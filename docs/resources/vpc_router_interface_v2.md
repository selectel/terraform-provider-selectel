# selectel_vpc_router_interface_v2

Creates and manages an interface that attaches a cloud router to a network using the v2 public API. For more information about cloud routers, see the [official Selectel documentation](https://docs.selectel.ru/en/cloud-servers/cloud-networks/cloud-routers/).

If you are upgrading from a version earlier than 9.1.0, follow the [upgrade guide](https://registry.terraform.io/providers/selectel/selectel/latest/docs/guides/upgrading_to_version_9_1) to migrate your resources from the OpenStack provider.

## Example Usage

```terraform
# Router interface attached through a subnet
resource "selectel_vpc_router_interface_v2" "interface_1" {
  project_id = selectel_vpc_project_v2.project_1.id
  region     = "ru-6"
  router_id  = selectel_vpc_router_v2.router_1.id
  subnet_id  = selectel_vpc_network_subnet_v2.subnet_1.id
}
```

```terraform
# Router interface attached through an existing port
resource "selectel_vpc_router_interface_v2" "interface_2" {
  project_id = selectel_vpc_project_v2.project_1.id
  region     = "ru-6"
  router_id  = selectel_vpc_router_v2.router_1.id
  port_id    = selectel_vpc_port_v2.port_1.id
}
```

## Schema

### Required

- `project_id` (String) Unique identifier of the associated project, for example, `a07abc12310546f1b9291ab3013a7d75`. Retrieved from the [selectel_vpc_project_v2](https://registry.terraform.io/providers/selectel/selectel/latest/docs/resources/vpc_project_v2) resource. Learn more about [Projects](https://docs.selectel.ru/en/control-panel-actions/projects/about-projects/). Changing this creates a new router interface.
- `region` (String) Pool where the router interface is located, for example, `ru-6`. Learn more about available pools in [Product availability by location](https://docs.selectel.ru/en/infrastructure/product-availability-by-location/). Changing this creates a new router interface.
- `router_id` (String) Unique identifier of the router the network is attached to. Retrieved from the [selectel_vpc_router_v2](https://registry.terraform.io/providers/selectel/selectel/latest/docs/resources/vpc_router_v2) resource. Changing this creates a new router interface.

### Optional

- `force_destroy` (Boolean) Specifies if static routes of the router that point into the attached subnet are deleted before the interface is detached. The default value is `false`.
- `port_id` (String) Unique identifier of the port to attach. The port must have exactly one fixed IP. Retrieved from the [selectel_vpc_port_v2](https://registry.terraform.io/providers/selectel/selectel/latest/docs/resources/vpc_port_v2) resource. Specify either `port_id` or `subnet_id`. Changing this creates a new router interface.
- `subnet_id` (String) Unique identifier of the subnet to attach. The port for the interface is created automatically. Retrieved from the [selectel_vpc_network_subnet_v2](https://registry.terraform.io/providers/selectel/selectel/latest/docs/resources/vpc_network_subnet_v2) resource. Specify either `subnet_id` or `port_id`. Changing this creates a new router interface.
- `timeouts` (Block, Optional) (see [below for nested schema](#nestedblock--timeouts))

### Read-Only

- `id` (String) Unique identifier of the port the router is attached through, for example, `b311ce58-2658-46b5-b733-7a0f418703f2`.
- `network_id` (String) Unique identifier of the network containing the interface port.
