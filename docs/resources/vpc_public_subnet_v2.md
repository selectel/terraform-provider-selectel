# selectel_vpc_public_subnet_v2

Creates and manages a public subnet using public API v2. For more information about public subnets, see the [official Selectel documentation](https://docs.selectel.ru/en/cloud-servers/cloud-networks/public-subnets/).

If you are upgrading from a version earlier than 9.0.0, follow the [upgrade guide](https://registry.terraform.io/providers/selectel/selectel/latest/docs/guides/upgrading_to_version_9) to migrate your resources from the OpenStack provider.

## Example Usage

```terraform
resource "selectel_vpc_public_subnet_v2" "subnet_1" {
  project_id = selectel_vpc_project_v2.project_1.id
  region     = "ru-6"
}
```

## Schema

### Required

- `project_id` (String) Unique identifier of the associated project, for example, `a07abc12310546f1b9291ab3013a7d75`. Retrieved from the [selectel_vpc_project_v2](https://registry.terraform.io/providers/selectel/selectel/latest/docs/resources/vpc_project_v2) resource. Learn more about [Projects](https://docs.selectel.ru/en/control-panel-actions/projects/about-projects/). Changing this creates a new public subnet.
- `region` (String) Pool where the public subnet is located, for example, `ru-6`. Learn more about available pools in [Product availability by location](https://docs.selectel.ru/en/infrastructure/product-availability-by-location/). Changing this creates a new public subnet.

### Optional

- `ip_version` (String) Internet protocol version supported in the public subnet. Available versions are `ipv4` or `ipv6`. Default value is `ipv4`. Changing this creates a new public subnet. The default value is `ipv4`.
- `prefix_length` (Number) Prefix length of the public subnet. Available values are from `24` to `29`. Default value is `29`. Changing this creates a new public subnet. The default value is `29`.

### Read-Only

- `cidr` (String) CIDR of the public subnet.
- `id` (String) Unique identifier of the public subnet.
- `network_id` (String) Unique identifier of the parent service network.
- `servers` (Set of Object) List of cloud servers that are located in the public subnet. (see [below for nested schema](#nestedatt--servers))
- `status` (String) Status of the public subnet.
- `subnet_id` (String) Unique identifier of the associated subnet in the parent service network.
