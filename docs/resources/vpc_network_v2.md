# selectel_vpc_network_v2

Creates and manages a private network using public API v2. For more information about private networks, see the [official Selectel documentation](https://docs.selectel.ru/en/cloud-servers/cloud-networks/private-networks-and-subnets/).

If you are upgrading from a version earlier than 9.0.0, follow the [upgrade guide](https://registry.terraform.io/providers/selectel/selectel/latest/docs/guides/upgrading_to_version_9) to migrate your resources from the OpenStack provider.

## Example Usage

```terraform
resource "selectel_vpc_network_v2" "network_1" {
  project_id = selectel_vpc_project_v2.project_1.id
  region     = "ru-6"
}
```

## Schema

### Required

- `project_id` (String) Unique identifier of the associated project, for example, `a07abc12310546f1b9291ab3013a7d75`. Retrieved from the [selectel_vpc_project_v2](https://registry.terraform.io/providers/selectel/selectel/latest/docs/resources/vpc_project_v2) resource. Learn more about [Projects](https://docs.selectel.ru/en/control-panel-actions/projects/about-projects/). Changing this creates a new network.
- `region` (String) Pool where the network is located, for example, `ru-6`. Learn more about available pools in [Product availability by location](https://docs.selectel.ru/en/infrastructure/product-availability-by-location/). Changing this creates a new network.

### Optional

- `admin_state_up` (Boolean) Specifies if the network is administratively up. The default value is `true`.
- `availability_zone_hints` (List of String) Pool segments requested for allocating the network. Learn more about available pools in [Product availability by location](https://docs.selectel.ru/en/infrastructure/product-availability-by-location/). Changing this creates a new network.
- `description` (String) Description of the network.
- `dns_domain` (String) DNS domain of the network. Learn more about [Private DNS](https://docs.selectel.ru/en/cloud-servers/private-dns/).
- `name` (String) Name of the network.
- `tags` (Set of String) Tags of the network.
- `timeouts` (Block, Optional) (see [below for nested schema](#nestedblock--timeouts))

### Read-Only

- `all_tags` (Set of String) All tags of the network.
- `availability_zones` (List of String) Pool segments where the network is actually allocated.
- `blocked` (Boolean) Specifies if the network is administratively blocked.
- `external` (Boolean) Specifies if the network has an external routing facility.
- `id` (String) Unique identifier of the network.
- `is_dns_enabled` (Boolean) Specifies if the private DNS service is enabled for the network.
- `is_public` (Boolean) Specifies if the network is public.
- `mtu` (Number) Maximum transmission unit of the network.
- `port_security_enabled` (Boolean) Specifies if port security is enabled by default for the ports of the network.
- `shared` (Boolean) Specifies if the network can be accessed by any project.
- `status` (String) Status of the network.
- `subnets` (List of String) Unique identifiers of the subnets within the network.
