# selectel_vpc_port_v2

Creates and manages a port using public API v2. For more information about ports, see the [official Selectel documentation](https://docs.selectel.ru/en/cloud-servers/cloud-networks/ports/).

If you are upgrading from a version earlier than 9.0.0, follow the [upgrade guide](https://registry.terraform.io/providers/selectel/selectel/latest/docs/guides/upgrading_to_version_9) to migrate your resources from the OpenStack provider.

## Example Usage

```terraform
resource "selectel_vpc_port_v2" "port_1" {
  project_id = selectel_vpc_project_v2.project_1.id
  region     = "ru-6"
  network_id = selectel_vpc_network_v2.network_1.id
}
```

## Schema

### Required

- `network_id` (String) Unique identifier of the network the port belongs to. Retrieved from the [selectel_vpc_network_v2](https://registry.terraform.io/providers/selectel/selectel/latest/docs/resources/vpc_network_v2) resource. Changing this creates a new port.

Learn more about [Projects](https://docs.selectel.ru/en/control-panel-actions/projects/about-projects/). Changing this creates a new port.
- `region` (String) Pool where the port is located, for example, `ru-6`. Learn more about available pools in [Product availability by location](https://docs.selectel.ru/en/infrastructure/product-availability-by-location/). Changing this creates a new port.

### Optional

- `admin_state_up` (Boolean) Specifies if the port is administratively up. The default value is `true`.
- `allowed_address_pairs` (Block Set) Additional IP and MAC address pairs allowed on the port. (see [below for nested schema](#nestedblock--allowed_address_pairs))
- `description` (String) Description of the port.
- `device_id` (String) Unique identifier of the device the port is attached to. Changing this creates a new port.
- `device_owner` (String) Owner of the device the port is attached to. Changing this creates a new port.
- `dns_name` (String) DNS name of the port. Learn more about [Private DNS](https://docs.selectel.ru/en/cloud-servers/private-dns/).
- `extra_dhcp_option` (Block Set) Extra DHCP options configured on the port. (see [below for nested schema](#nestedblock--extra_dhcp_option))
- `fixed_ip` (Block List) Fixed IPs of the port. If neither is specified, allocates an address from one of the subnets of the network. Conflicts with `no_fixed_ip`. (see [below for nested schema](#nestedblock--fixed_ip))
- `mac_address` (String) MAC address of the port, for example `fa:16:3e:4c:2c:30`. If not specified, it allocates one automatically. Changing this creates a new port.
- `name` (String) Name of the port.
- `no_fixed_ip` (Boolean) Specifies whether to create the port without any fixed IP. Conflicts with `fixed_ip`. The default value is `false`.
- `no_security_groups` (Boolean) Specifies whether to create the port without any security group. Conflicts with `security_group_ids`. The default value is `false`.
- `security_group_ids` (Set of String) Unique identifiers of security groups assigned to the port. If not specified, the port gets the default security group of the project. Retrieved from the [selectel_vpc_secgroup_v2](https://registry.terraform.io/providers/selectel/selectel/latest/docs/resources/vpc_secgroup_v2) resource. Conflicts with `no_security_groups`.
- `tags` (Set of String) Tags of the port.
