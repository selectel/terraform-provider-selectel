# selectel_vpc_router_routes_v2

Creates and manages the complete set of static routes of a cloud router using the v2 public API. For more information about static routes, see the [official Selectel documentation](https://docs.selectel.ru/en/cloud-servers/cloud-networks/static-routes/).

Do not manage the same router with both resources: `selectel_vpc_router_route_v2` and `selectel_vpc_router_routes_v2`.

If you are upgrading from a version earlier than 9.1.0, follow the [upgrade guide](https://registry.terraform.io/providers/selectel/selectel/latest/docs/guides/upgrading_to_version_9) to migrate your resources from the OpenStack provider.

## Example Usage

```terraform
resource "selectel_vpc_router_routes_v2" "routes_1" {
  project_id = selectel_vpc_project_v2.project_1.id
  region     = "ru-6"
  router_id  = selectel_vpc_router_v2.router_1.id
  depends_on = [selectel_vpc_router_interface_v2.interface_1]

  routes {
    destination_cidr = "10.0.0.0/8"
    next_hop         = "192.168.199.10"
  }

  routes {
    destination_cidr = "172.16.0.0/12"
    next_hop         = "192.168.199.10"
  }
}
```

## Schema

### Required

- `project_id` (String) Unique identifier of the associated project, for example, `a07abc12310546f1b9291ab3013a7d75`. Retrieved from the [selectel_vpc_project_v2](https://registry.terraform.io/providers/selectel/selectel/latest/docs/resources/vpc_project_v2) resource. Learn more about [Projects](https://docs.selectel.ru/en/control-panel-actions/projects/about-projects/). Changing this creates a new route set.
- `region` (String) Pool where the route set is located, for example, `ru-6`. Learn more about available pools in [Product availability by location](https://docs.selectel.ru/en/infrastructure/product-availability-by-location/). Changing this creates a new route set.
- `router_id` (String) Unique identifier of the router whose routes are managed. Retrieved from the [selectel_vpc_router_v2](https://registry.terraform.io/providers/selectel/selectel/latest/docs/resources/vpc_router_v2) resource. Changing this creates a new route set.

### Optional

- `routes` (Block Set) Static routes to add to the router. (see [below for nested schema](#nestedblock--routes))

### Read-Only

- `id` (String) Unique identifier of the router whose routes are managed, for example, `b311ce58-2658-46b5-b733-7a0f418703f2`.

<a id="nestedblock--routes"></a>
### Nested Schema for `routes`

Required:

- `destination_cidr` (String) Destination CIDR of the route, for example, `10.0.0.0/8`.
- `next_hop` (String) IP address of the next hop gateway, for example, `192.168.199.10`. Must be an address in a subnet connected to one of the router's internal interfaces. Cannot be an address from the router's external gateway subnet.
