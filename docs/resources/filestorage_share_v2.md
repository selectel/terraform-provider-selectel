# selectel_filestorage_share_v2

Creates and manages a file storage in File Storage using the v2 public API. The file storage is placed in a private network and is created without access rules, so no client can mount it until you add `selectel_filestorage_share_access_v2`. The size can only increase. For more information about file storage, see the [official Selectel documentation](https://docs.selectel.ru/en/file-storage/about/about-file-storage/).

## Example Usage

### Create an NFS file storage in a private subnet

```terraform
resource "selectel_filestorage_share_v2" "share_1" {
  project_id  = selectel_vpc_project_v2.project_1.id
  region      = "ru-6"
  name        = "data"
  share_proto = "NFS"
  share_type  = "basic.ru-6a"
  size        = 50
  network_id  = selectel_vpc_network_v2.network_1.id
  subnet_id   = selectel_vpc_network_subnet_v2.subnet_1.id
}

output "share_1_mount_path" {
  value = one([for location in selectel_filestorage_share_v2.share_1.export_locations : location.path if location.preferred])
}
```

### Create a file storage in a pool segment from the list of availability zones

```terraform
data "selectel_filestorage_availability_zones_v2" "availability_zones_1" {
  project_id = selectel_vpc_project_v2.project_1.id
  region     = "ru-6"
}

resource "selectel_filestorage_share_v2" "share_1" {
  project_id  = selectel_vpc_project_v2.project_1.id
  region      = "ru-6"
  name        = "data"
  share_proto = "NFS"
  share_type  = "basic.${data.selectel_filestorage_availability_zones_v2.availability_zones_1.names[0]}"
  size        = 50
  network_id  = selectel_vpc_network_v2.network_1.id
  subnet_id   = selectel_vpc_network_subnet_v2.subnet_1.id
}
```

### Create a CIFS file storage with a fixed IP address

```terraform
resource "selectel_filestorage_share_v2" "share_1" {
  project_id  = selectel_vpc_project_v2.project_1.id
  region      = "ru-6"
  name        = "windows-data"
  share_proto = "CIFS"
  share_type  = "basic.ru-6a"
  size        = 50
  network_id  = selectel_vpc_network_v2.network_1.id
  subnet_id   = selectel_vpc_network_subnet_v2.subnet_1.id
  ip          = "192.168.199.50"

  metadata = {
    owner = "team"
  }
}
```

## Schema

### Required

- `network_id` (String) Unique identifier of the private network of the file storage. The format is a lowercase UUID. You can retrieve the network ID from the [selectel_vpc_network_v2](https://registry.terraform.io/providers/selectel/selectel/latest/docs/resources/vpc_network_v2) resource. Changing this creates a new file storage.
- `project_id` (String) Unique identifier of the associated project, for example, `a07abc12310546f1b9291ab3013a7d75`. The value cannot be empty or start or end with whitespace. You can retrieve the project ID from the [selectel_vpc_project_v2](https://registry.terraform.io/providers/selectel/selectel/latest/docs/resources/vpc_project_v2) resource. Learn more about [Projects](https://docs.selectel.ru/en/control-panel-actions/projects/about-projects/). Changing this creates a new file storage.
- `region` (String) Pool where the file storage is located, for example, `ru-6`. The value cannot be empty or start or end with whitespace. Learn more about available pools in [Product availability by location](https://docs.selectel.ru/en/infrastructure/product-availability-by-location/#file-storage). Changing this creates a new file storage.
- `share_proto` (String) File storage protocol. Available values are `NFS` and `CIFS`. Changing this creates a new file storage.
- `share_type` (String) Name of the file storage type. The value cannot be empty or start or end with whitespace. The name format is `<type>.<pool_segment>`, where `<type>` is `basic` for HDD Basic, `universal` for SSD Universal, or `fast` for SSD Fast, for example, `basic.ru-6a` for HDD Basic in the `ru-6a` pool segment. The type also sets the pool segment of the file storage. Not every type is available in every pool segment: see [File Storage availability](https://docs.selectel.ru/en/infrastructure/product-availability-by-location/#file-storage). A UUID is rejected: use the type name. You can retrieve the pool segments with the [selectel_filestorage_availability_zones_v2](https://registry.terraform.io/providers/selectel/selectel/latest/docs/data-sources/filestorage_availability_zones_v2) data source. Learn more about [File storage types](https://docs.selectel.ru/en/file-storage/about/about-file-storage/#file-storage-types). Changing this creates a new file storage.
- `size` (Number) Size of the file storage in GB. The minimum value is `50`. Only increases are supported. Unmount the file storage from all clients before increasing the size and mount it again after.
- `subnet_id` (String) Unique identifier of the private subnet of the file storage. The format is a lowercase UUID. A subnet of a cloud network gives access to cloud servers and Managed Kubernetes clusters in the same pool. To connect dedicated servers or servers in other pools, use a subnet connected to a global router: see [Connect a File Storage](https://docs.selectel.ru/en/file-storage/add/). You can retrieve the subnet ID from the [selectel_vpc_network_subnet_v2](https://registry.terraform.io/providers/selectel/selectel/latest/docs/resources/vpc_network_subnet_v2) resource. Changing this creates a new file storage.

## Import

### In Terraform 1.5.0 and later

Use the [`import` block](https://developer.hashicorp.com/terraform/language/import) with the `id` attribute:

```terraform
# Set the project and pool in the provider configuration or the
# INFRA_PROJECT_ID and INFRA_REGION environment variables.
# Import does not restore `metadata`: after import, list in it only the keys you want Terraform to manage.
# A file storage accessible to all addresses of its subnet has a 0.0.0.0/0 access rule:
# import it as selectel_filestorage_share_access_v2.
import {
  to = selectel_filestorage_share_v2.share_1
  id = "<share_uuid>"
}
```

### All versions

Use the [`terraform import` command](https://developer.hashicorp.com/terraform/cli/commands/import):

```shell
# Import the existing file storage by its UUID.
# Import does not restore `metadata`: after import, list in it only the keys you want Terraform to manage.
# A file storage accessible to all addresses of its subnet has a 0.0.0.0/0 access rule:
# import it as selectel_filestorage_share_access_v2.
# Set the project and pool containing the file storage.
export OS_DOMAIN_NAME=<domain_name>
export OS_USERNAME=<username>
export OS_PASSWORD=<password>
export INFRA_PROJECT_ID=<project_id>
export INFRA_REGION=<region>

terraform import selectel_filestorage_share_v2.share_1 <share_uuid>
```

`<domain_name>`, `<username>`, and `<password>` are the arguments of the [provider configuration](https://registry.terraform.io/providers/selectel/selectel/latest/docs).

## Uncertain creation

If the API gives no definite answer to the create request, the resource looks for the file storage by the `selectel_tf_create_token` metadata key. When none appears, the apply fails, and the resource stays in state as `pending:<token>`. Refresh and destroy fail until the file storage appears. When it appears, the next refresh replaces the temporary ID with its UUID, and the next apply replaces the file storage; to keep it, run `terraform untaint` for the resource. If it does not appear, run `terraform state rm` for the resource, and the next apply creates it again.
