# selectel_vpc_port_forwarding_v2

Creates and manages a port-forwarding rule of a public floating IP address using the v2 public API. For more information about public floating IP addresses, see the [official Selectel documentation](https://docs.selectel.ru/en/cloud-servers/cloud-networks/public-floating-ip-addresses/).

If you are upgrading from a version earlier than 9.0.0, follow the [upgrade guide](https://registry.terraform.io/providers/selectel/selectel/latest/docs/guides/upgrading_to_version_9) to migrate your resources from the OpenStack provider.

## Example Usage

```terraform
resource "selectel_vpc_port_forwarding_v2" "port_forwarding_1" {
  project_id          = selectel_vpc_project_v2.project_1.id
  region              = "ru-6"
  floatingip_id       = selectel_vpc_floatingip_v2.floatingip_1.id
  internal_port_id    = selectel_vpc_port_v2.port_1.id
  internal_ip_address = "192.168.199.50"
  internal_port       = 80
  external_port       = 8080
  protocol            = "tcp"
}
```

## Schema

### Required

- `floatingip_id` (String) Unique identifier of the public floating IP address the rule belongs to. Retrieved from the [selectel_vpc_floatingip_v2](https://registry.terraform.io/providers/selectel/selectel/latest/docs/resources/vpc_floatingip_v2) resource. Changing this creates a new port forwarding rule.
- `internal_ip_address` (String) IPv4 address to which traffic is forwarded. Must be one of the fixed IPs of the internal port `internal_port_id`.
- `internal_port_id` (String) Unique identifier of the port traffic is forwarded to. Retrieved from the [selectel_vpc_port_v2](https://registry.terraform.io/providers/selectel/selectel/latest/docs/resources/vpc_port_v2) resource.
- `project_id` (String) Unique identifier of the associated project, for example, `a07abc12310546f1b9291ab3013a7d75`. Retrieved from the [selectel_vpc_project_v2](https://registry.terraform.io/providers/selectel/selectel/latest/docs/resources/vpc_project_v2) resource. Learn more about [Projects](https://docs.selectel.ru/en/control-panel-actions/projects/about-projects/). Changing this creates a new port forwarding rule.
- `protocol` (String) Protocol of the forwarded traffic. Available values are `tcp`, `udp`, `icmp`, `ipv6-icmp`, `sctp`, and `dccp`.
- `region` (String) Pool where the port forwarding rule is located, for example, `ru-6`. Learn more about available pools in [Product availability by location](https://docs.selectel.ru/en/infrastructure/product-availability-by-location/). Changing this creates a new port forwarding rule.

### Optional

- `description` (String) Description of the rule.
- `external_port` (Number) Port traffic arrives at. The available range is from 1 to 65535. Specify either `external_port` or `external_port_range`.
- `external_port_range` (String) Range of ports traffic arrives at, for example, `9000:9002`. Must have the same size as `internal_port_range`. If `internal_port` is specified instead, every port of the range is forwarded to it. The available range is from 1 to 65535. Specify either `external_port_range` or `external_port`.
- `internal_port` (Number) Port traffic is forwarded to. The available range is from 1 to 65535. Specify either `internal_port` or `internal_port_range`.
- `internal_port_range` (String) Range of ports traffic is forwarded to, for example, `8000:8002`. Must have the same size as `external_port_range`. To forward every port of `external_port_range` to one internal port, specify `internal_port` instead. The available range is from 1 to 65535. Specify either `internal_port_range` or `internal_port`.
- `timeouts` (Block, Optional) (see [below for nested schema](#nestedblock--timeouts))
