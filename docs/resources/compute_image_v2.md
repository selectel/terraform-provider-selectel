# selectel_compute_image_v2

Creates and manages an image in Cloud Servers using the v2 public API. Terraform waits until the image becomes `active`. For more information about images, see the [official Selectel documentation](https://docs.selectel.ru/en/cloud-servers/images/about-images/).

If the creation fails after the image is registered, for example, because the download fails or the wait times out, Terraform keeps the image in the state and marks it as tainted. The next apply replaces the image.

## Example Usage

### Upload an image from a local file

```terraform
resource "selectel_compute_image_v2" "image_1" {
  project_id       = selectel_vpc_project_v2.project_1.id
  region           = "ru-6"
  name             = "image-1"
  container_format = "bare"
  disk_format      = "qcow2"
  local_file_path  = "/var/lib/images/disk.qcow2"
}
```

### Create an image from a URL

```terraform
resource "selectel_compute_image_v2" "image_1" {
  project_id       = selectel_vpc_project_v2.project_1.id
  region           = "ru-6"
  name             = "ubuntu-24.04"
  container_format = "bare"
  disk_format      = "qcow2"
  image_source_url = "https://cloud-images.ubuntu.com/noble/current/noble-server-cloudimg-amd64.img"
  min_disk_gb      = 5

  properties = {
    os_distro = "ubuntu"
  }
}
```

## Schema

### Required

- `container_format` (String) Container format of the image. Available values are `bare`, `ovf`, `aki`, `ari`, `ami`, `ova`, `docker`, and `compressed`. Learn more about [supported formats](https://docs.selectel.ru/en/cloud-servers/images/about-images/#own-images). Changing this creates a new image.
- `disk_format` (String) Disk format of the image. Available values are `raw`, `vhd`, `vhdx`, `vmdk`, `vdi`, `iso`, `ploop`, `qcow2`, `aki`, `ari`, and `ami`. The API does not convert the image data, so the value must match the format of the file. Learn more about [supported formats](https://docs.selectel.ru/en/cloud-servers/images/about-images/#own-images). Changing this creates a new image.
- `name` (String) Name of the image. The minimum length is `1` character. The maximum length is `255` characters.
- `project_id` (String) Unique identifier of the associated project, for example, `a07abc12310546f1b9291ab3013a7d75`. The value cannot be empty or start or end with whitespace. You can retrieve the project ID from the [selectel_vpc_project_v2](https://registry.terraform.io/providers/selectel/selectel/latest/docs/resources/vpc_project_v2) resource. Learn more about [Projects](https://docs.selectel.ru/en/control-panel-actions/projects/about-projects/). Changing this creates a new image.
- `region` (String) Pool where the image is located, for example, `ru-6`. The value cannot be empty or start or end with whitespace. Learn more about available pools in [Product availability by location](https://docs.selectel.ru/en/infrastructure/product-availability-by-location/). Changing this creates a new image.

### Optional

- `hidden` (Boolean) Specifies if the image is hidden from the default image list. The default value is `false`.
- `image_source_url` (String) URL of the image file that the API downloads. The URL must start with `http://` or `https://`. This argument conflicts with `local_file_path`. The URL must be reachable from the Selectel network. The API stores the file as is and does not unpack archives. When Terraform creates or replaces the image, one of `local_file_path` and `image_source_url` is required. Import does not restore this argument. Setting a source on an image that has none, such as an imported image, or removing the source without setting another one does not replace the image. Changing this creates a new image.
- `local_file_path` (String) Path to the image file on the machine that runs Terraform. The minimum length is `1` character. This argument conflicts with `image_source_url`. After the upload, Terraform compares the SHA-512 checksum of the file with the checksum reported by the API. When Terraform creates or replaces the image, one of `local_file_path` and `image_source_url` is required. Import does not restore this argument. Setting a source on an image that has none, such as an imported image, or removing the source without setting another one does not replace the image. Changing this creates a new image.
- `min_disk_gb` (Number) Minimum disk size in GB required to boot the image. The minimum value is `0`. If omitted, the API derives the value from the image data.
- `min_ram_mb` (Number) Minimum RAM in MB required to boot the image. The minimum value is `0`. The default value is `0`.
- `properties` (Map of String) Key-value pairs of custom image properties, for example, `os_distro = "ubuntu"`. The maximum number of properties is `128`, including the properties added by the API. Each key must contain from `1` to `255` characters and cannot start or end with whitespace. Keys that differ only in letter case are not allowed. Keys of image fields, such as `name`, `min_disk`, or `os_hidden`, are not accepted: set the matching argument instead. The `os_glance` prefix is reserved by the API. Properties added by the API are available in `service_properties`. Import does not restore this argument.
- `protected` (Boolean) Specifies if the image is protected from deletion. Terraform enables the protection after the image becomes `active`. To destroy or replace a protected image, first set `protected` to `false` and apply this change on its own. The default value is `false`.
- `tags` (Set of String) Set of image tags. The maximum number of tags is `128`. Each tag must contain from `1` to `255` characters. Tags are case-sensitive. Tags added outside of Terraform appear as changes in the plan. Import restores this argument.
- `timeouts` (Block, Optional) Timeouts for image operations. (see [below for nested schema](#nestedblock--timeouts))
- `visibility` (String) Visibility of the image. Available values are `private`, `shared`, and `community`. Use `shared` to grant access to other projects with the [selectel_compute_image_access_v2](https://registry.terraform.io/providers/selectel/selectel/latest/docs/resources/compute_image_access_v2) resource. A `community` image is available to all projects in the pool. The default value is `private`. Learn more about [image sharing](https://docs.selectel.ru/en/cloud-servers/images/transfer-image/#configure-access-to-image).

### Read-Only

- `checksum` (String) MD5 checksum of the image data.
- `created_at` (String) Time when the image was created in the RFC 3339 format.
- `id` (String) Unique identifier of the image.
- `owner` (String) Unique identifier of the project that owns the image.
- `service_properties` (Map of String) All image properties returned by the API, including those that are not set in `properties`.
- `size_bytes` (Number) Size of the image data in bytes.
- `status` (String) Status of the image.
- `updated_at` (String) Time when the image was last updated in the RFC 3339 format.

## Import

### In Terraform 1.5.0 and later

Use the [`import` block](https://developer.hashicorp.com/terraform/language/import) with the `id` attribute:

```terraform
# Set the project and pool in the provider configuration or the
# INFRA_PROJECT_ID and INFRA_REGION environment variables.
# `local_file_path`, `image_source_url`, and `properties` are not restored.
# Setting `local_file_path` or `image_source_url` after import does not replace the image.
import {
  to = selectel_compute_image_v2.image_1
  id = "<image_uuid>"
}
```

### All versions

Use the [`terraform import` command](https://developer.hashicorp.com/terraform/cli/commands/import):

```shell
# Import the existing image by its UUID.
# `local_file_path`, `image_source_url`, and `properties` are not restored.
# Setting `local_file_path` or `image_source_url` after import does not replace the image.
# Set the project and pool containing the image.
export OS_DOMAIN_NAME=<domain_name>
export OS_USERNAME=<username>
export OS_PASSWORD=<password>
export INFRA_PROJECT_ID=<project_id>
export INFRA_REGION=<region>

terraform import selectel_compute_image_v2.image_1 <image_uuid>
```

`<domain_name>`, `<username>`, and `<password>` are the arguments of the [provider configuration](https://registry.terraform.io/providers/selectel/selectel/latest/docs).
