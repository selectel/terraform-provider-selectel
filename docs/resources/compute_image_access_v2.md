# selectel_compute_image_access_v2

Creates and manages access of another project to a shared image in Cloud Servers using the v2 public API. Access works only within a pool: the receiving project can use the image only in the pool where the image is located. The image must have `visibility = "shared"`. Granting access requires a role that allows managing image access in the project. For more information about access to images and the roles, see the [official Selectel documentation](https://docs.selectel.ru/en/cloud-servers/images/manage-access/).

The resource is managed in the project that owns the image. The receiving project accepts or rejects access with the [selectel_compute_image_access_accept_v2](https://registry.terraform.io/providers/selectel/selectel/latest/docs/resources/compute_image_access_accept_v2) resource. If the image visibility changes from `shared`, the API keeps the access but hides it and stops applying it: Terraform removes the resource from the state, and the access applies again when the image is shared again. To revoke access, destroy the resource before you change the image visibility. To manage hidden access after the image is shared again, import it: creating it fails because the access already exists.

## Example Usage

### Grant another project access to a shared image

```terraform
resource "selectel_compute_image_access_v2" "image_access_1" {
  project_id = selectel_vpc_project_v2.project_1.id
  region     = "ru-6"
  image_id   = selectel_compute_image_v2.image_1.id
  member_id  = selectel_vpc_project_v2.project_2.id
}
```

## Schema

### Required

- `image_id` (String) Unique identifier of the shared image. The format is a lowercase UUID. You can retrieve the image ID from the [selectel_compute_image_v2](https://registry.terraform.io/providers/selectel/selectel/latest/docs/resources/compute_image_v2) resource. Changing this creates a new image access.
- `member_id` (String) Unique identifier of the project that receives access. The value cannot be empty or start or end with whitespace. You can retrieve the project ID from the [selectel_vpc_project_v2](https://registry.terraform.io/providers/selectel/selectel/latest/docs/resources/vpc_project_v2) resource. Changing this creates a new image access.
- `project_id` (String) Unique identifier of the associated project, for example, `a07abc12310546f1b9291ab3013a7d75`. The value cannot be empty or start or end with whitespace. You can retrieve the project ID from the [selectel_vpc_project_v2](https://registry.terraform.io/providers/selectel/selectel/latest/docs/resources/vpc_project_v2) resource. Learn more about [Projects](https://docs.selectel.ru/en/control-panel-actions/projects/about-projects/). Changing this creates a new image access.
- `region` (String) Pool where the image access is located, for example, `ru-6`. The value cannot be empty or start or end with whitespace. Learn more about available pools in [Product availability by location](https://docs.selectel.ru/en/infrastructure/product-availability-by-location/). Changing this creates a new image access.

### Read-Only

- `created_at` (String) Time when the access was granted in the RFC 3339 format.
- `id` (String) Unique identifier of the image access in the `<image_id>/<member_id>` format.
- `status` (String) Status of the access: `pending`, `accepted`, or `rejected`. A new access is `pending`.
- `updated_at` (String) Time when the access was last updated in the RFC 3339 format.

## Import

### In Terraform 1.5.0 and later

Use the [`import` block](https://developer.hashicorp.com/terraform/language/import) with the `id` attribute:

```terraform
# Set the project that owns the image and its pool in the provider configuration
# or the INFRA_PROJECT_ID and INFRA_REGION environment variables.
import {
  to = selectel_compute_image_access_v2.image_access_1
  id = "<image_uuid>/<member_id>"
}
```

### All versions

Use the [`terraform import` command](https://developer.hashicorp.com/terraform/cli/commands/import):

```shell
# Import the existing image access by the image UUID and the ID of the receiving project.
# Set the project that owns the image and its pool.
export OS_DOMAIN_NAME=<domain_name>
export OS_USERNAME=<username>
export OS_PASSWORD=<password>
export INFRA_PROJECT_ID=<project_id>
export INFRA_REGION=<region>

terraform import selectel_compute_image_access_v2.image_access_1 <image_uuid>/<member_id>
```

`<domain_name>`, `<username>`, and `<password>` are the arguments of the [provider configuration](https://registry.terraform.io/providers/selectel/selectel/latest/docs).
