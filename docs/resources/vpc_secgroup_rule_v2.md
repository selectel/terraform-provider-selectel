# selectel_vpc_secgroup_rule_v2

Creates and manages a rule of a security group using public API v2. For more information about security groups, see the [official Selectel documentation](https://docs.selectel.ru/en/cloud-servers/security-groups/).

If you are upgrading from a version earlier than 9.0.0, follow the [upgrade guide](https://registry.terraform.io/providers/selectel/selectel/latest/docs/guides/upgrading_to_version_9) to migrate your resources from the OpenStack provider.

## Example Usage

```terraform
# Allowing inbound SSH from one subnet
resource "selectel_vpc_secgroup_rule_v2" "rule_1" {
  project_id        = selectel_vpc_project_v2.project_1.id
  region            = "ru-6"
  security_group_id = selectel_vpc_secgroup_v2.secgroup_1.id
  direction         = "ingress"
  ethertype         = "IPv4"
  protocol          = "tcp"
  port_range_min    = 22
  port_range_max    = 22
  remote_ip_prefix  = "192.168.199.0/24"
}

# Allowing outbound traffic to the members of another group
resource "selectel_vpc_secgroup_rule_v2" "rule_2" {
  project_id        = selectel_vpc_project_v2.project_1.id
  region            = "ru-6"
  security_group_id = selectel_vpc_secgroup_v2.secgroup_1.id
  direction         = "egress"
  ethertype         = "IPv4"
  remote_group_id   = selectel_vpc_secgroup_v2.secgroup_2.id
}
```

## Schema

### Required

- `direction` (String) Direction of the traffic. Available values are `ingress` or `egress`. Changing this creates a new security group rule.
- `ethertype` (String) Internet protocol version of the rule. Available values are `IPv4` or `IPv6`. Changing this creates a new security group rule.
- `project_id` (String) Unique identifier of the associated project, for example, `a07abc12310546f1b9291ab3013a7d75`. Retrieved from the [selectel_vpc_project_v2](https://registry.terraform.io/providers/selectel/selectel/latest/docs/resources/vpc_project_v2) resource. Learn more about [Projects](https://docs.selectel.ru/en/control-panel-actions/projects/about-projects/). Changing this creates a new security group rule.
- `region` (String) Pool where the security group rule is located, for example, `ru-6`. Learn more about available pools in [Product availability by location](https://docs.selectel.ru/en/infrastructure/product-availability-by-location/). Changing this creates a new security group rule.
- `security_group_id` (String) Unique identifier of the security group the rule belongs to. Retrieved from the [selectel_vpc_secgroup_v2](https://registry.terraform.io/providers/selectel/selectel/latest/docs/resources/vpc_secgroup_v2) resource. Changing this creates a new security group rule.

### Optional

- `description` (String) Description of the rule. Changing this creates a new security group rule.
- `port_range_max` (Number) Upper bound of the port range. Available values are from `0` to `65535`. Requires `protocol` and `port_range_min`. With `protocol = "icmp"`, specifies the ICMP **code** from `0` to `255`. Learn more about the security group rules in the [official Selectel documentation](https://docs.selectel.ru/en/cloud-servers/security-groups/about-security-groups/). Changing this creates a new security group rule.
- `port_range_min` (Number) Lower bound of the port range. Available values are from `0` to `65535`. Requires `protocol`. With `protocol = "icmp"`, specifies the ICMP **type** from `0` to `255` and can be set without `port_range_max`. Learn more about the security group rules in the [official Selectel documentation](https://docs.selectel.ru/en/cloud-servers/security-groups/about-security-groups/). Changing this creates a new security group rule.
- `protocol` (String) Protocol of the rule. As an alternative, you can specify an IP protocol number from `0` to `255` as a string. If omitted, the rule matches any protocol. If omitted, the rule matches any protocol. Learn more about the security group rules in the [official Selectel documentation](https://docs.selectel.ru/en/cloud-servers/security-groups/about-security-groups/). Changing this creates a new security group rule.
- `remote_group_id` (String) Unique identifier of the security group whose members the rule matches. Conflicts with `remote_ip_prefix`. Retrieved from the [selectel_vpc_secgroup_v2](https://registry.terraform.io/providers/selectel/selectel/latest/docs/data-sources/vpc_secgroup_v2) data source. Changing this creates a new security group rule.
