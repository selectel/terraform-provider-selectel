# selectel_vpc_floatingip_associate_v2

Creates and manages the association between an existing public floating IP address and an existing port using public API v2. For more information about public floating IP addresses, see the [official Selectel documentation](https://docs.selectel.ru/en/cloud-servers/cloud-networks/public-floating-ip-addresses/).

The resource manages only the association and never creates or deletes the public floating IP address or the port.

If you are upgrading from a version earlier than 9.0.0, follow the [upgrade guide](https://registry.terraform.io/providers/selectel/selectel/latest/docs/guides/upgrading_to_version_9) to migrate your resources from the OpenStack provider.

## Example Usage

```terraform
resource "selectel_vpc_floatingip_associate_v2" "association_1" {
  project_id  = selectel_vpc_project_v2.project_1.id
  region      = "ru-6"
  floating_ip = selectel_vpc_floatingip_v2.floatingip_1.floating_ip_address
  port_id     = selectel_vpc_port_v2.port_1.id
  depends_on  = [selectel_vpc_router_interface_v2.interface_1]
}
```

- `project_id` (String) Unique identifier of the associated project, for example, `a07abc12310546f1b9291ab3013a7d75`. Retrieved from the [selectel_vpc_project_v2](https://registry.terraform.io/providers/selectel/selectel/latest/docs/resources/vpc_project_v2) resource. Learn more about [Projects](https://docs.selectel.ru/en/control-panel-actions/projects/about-projects/). Changing this creates a new association.
- `region` (String) Pool where the public floating IP address and port are located, for example, `ru-6`. Learn more about available pools in [Product availability by location](https://docs.selectel.ru/en/infrastructure/product-availability-by-location/). Changing this creates a new association.
