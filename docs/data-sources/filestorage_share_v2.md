# selectel_filestorage_share_v2

Provides a file storage in File Storage. The data source finds the file storage by `share_id` or exactly one file storage of the project that matches all set selectors. Without `share_id` and selectors, the project must have exactly one file storage in the pool. For more information about file storage, see the [official Selectel documentation](https://docs.selectel.ru/en/file-storage/about/about-file-storage/).

## Example Usage

```terraform
data "selectel_filestorage_share_v2" "share_1" {
  project_id = selectel_vpc_project_v2.project_1.id
  region     = "ru-6"
  name       = "data"
}
```

## Schema

### Required

- `project_id` (String) Unique identifier of the associated project, for example, `a07abc12310546f1b9291ab3013a7d75`. The value cannot be empty or start or end with whitespace. You can retrieve the project ID from the [selectel_vpc_project_v2](https://registry.terraform.io/providers/selectel/selectel/latest/docs/resources/vpc_project_v2) resource. Learn more about [Projects](https://docs.selectel.ru/en/control-panel-actions/projects/about-projects/).
- `region` (String) Pool where the file storage is located, for example, `ru-6`. The value cannot be empty or start or end with whitespace. Learn more about available pools in [Product availability by location](https://docs.selectel.ru/en/infrastructure/product-availability-by-location/#file-storage).

### Optional

- `description` (String) Exact description of the file storage. The minimum length is `1` character. This argument conflicts with `share_id`. When omitted, it returns the description of the found file storage.
- `export_location_path` (String) Mount path of the file storage, for example, `192.168.199.5:/shares/share-<id>`. The minimum length is `1` character. This argument conflicts with `share_id`.
- `metadata` (Map of String) Key-value pairs of the file storage. This argument conflicts with `share_id`. As a selector, it matches a file storage that has all the pairs among all its keys, including the keys of the service. When omitted, it returns the keys of the found file storage without the reserved keys, so you can copy it to `selectel_filestorage_share_v2`.
- `name` (String) Exact name of the file storage. The minimum length is `1` character. This argument conflicts with `share_id`. When omitted, it returns the name of the found file storage. To get the file storage name, use the [OpenStack CLI](https://docs.selectel.ru/en/cloud-servers/tools/openstack-cli/) command `openstack share list` and copy the `Name` field.
- `share_id` (String) Unique identifier of the file storage. The format is a lowercase UUID. This argument conflicts with `name`, `description`, `status`, `export_location_path`, and `metadata`. To get the file storage ID, use the [OpenStack CLI](https://docs.selectel.ru/en/cloud-servers/tools/openstack-cli/) command `openstack share list` and copy the `ID` field.
- `status` (String) Status of the file storage, for example, `available`. The minimum length is `1` character. This argument conflicts with `share_id`. When omitted, it returns the status of the found file storage.
