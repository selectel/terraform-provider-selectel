# selectel_compute_volume_type_v3

Provides a network volume type in Cloud Servers. The data source finds exactly one type by UUID, `default`, or exact name. For more information about volume types, see the [official Selectel documentation](https://docs.selectel.ru/en/cloud-servers/volumes/about-network-volumes/#network-volume-types).

## Example Usage

```terraform
data "selectel_compute_volume_type_v3" "volume_type_1" {
  project_id     = selectel_vpc_project_v2.project_1.id
  region         = "ru-6"
  volume_type_id = "default"
}
```

## Schema

### Required

- `project_id` (String) Unique identifier of the associated project, for example, `a07abc12310546f1b9291ab3013a7d75`. The value cannot be empty or start or end with whitespace. You can retrieve the project ID from the [selectel_vpc_project_v2](https://registry.terraform.io/providers/selectel/selectel/latest/docs/resources/vpc_project_v2) resource. Learn more about [Projects](https://docs.selectel.ru/en/control-panel-actions/projects/about-projects/).
- `region` (String) Pool where the volume type is located, for example, `ru-6`. The value cannot be empty or start or end with whitespace. Learn more about available pools in [Product availability by location](https://docs.selectel.ru/en/infrastructure/product-availability-by-location/#network-volumes).

### Optional

- `name` (String) Exact volume type name. The minimum length is `1` character. Set exactly one of `volume_type_id` and `name`. The name format is `<volume_type>.<availability_zone>`, for example, `fast2.ru-6a` for SSD Fast v2 in the `ru-6a` pool segment. ID lookups return the API name here. To get the volume type name, use the [OpenStack CLI](https://docs.selectel.ru/en/cloud-servers/tools/openstack-cli/) command `openstack volume type list` and copy the `Name` field. Learn more about [the list of network volume types](https://docs.selectel.ru/en/cloud-servers/volumes/about-network-volumes/#network-volume-types-list).
- `volume_type_id` (String) Unique identifier of the volume type. The format is a lowercase UUID or `default` to select the default volume type. Set exactly one of `volume_type_id` and `name`. To get the volume type ID, use the [OpenStack CLI](https://docs.selectel.ru/en/cloud-servers/tools/openstack-cli/) command `openstack volume type list` and copy the `ID` field.

### Read-Only

- `description` (String) Volume type description.
- `extra_specs` (Map of String) Type specifications visible to the current role.
- `id` (String) Unique identifier of the volume type.
- `is_public` (Boolean) Whether the type is public.
- `supports_custom_iops` (Boolean) Whether the type allows custom `total_iops_sec` metadata.
