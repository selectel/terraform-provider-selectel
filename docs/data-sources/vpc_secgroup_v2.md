# selectel_vpc_secgroup_v2

Provides a security group. For more information about security groups, see the [official Selectel documentation](https://docs.selectel.ru/en/cloud-servers/security-groups/).

If you are upgrading from a version earlier than 9.0.0, follow the [upgrade guide](https://registry.terraform.io/providers/selectel/selectel/latest/docs/guides/upgrading_to_version_9) to migrate your resources from the OpenStack provider.

## Example Usage

```terraform
# Security group found by name
data "selectel_vpc_secgroup_v2" "secgroup_1" {
  project_id = selectel_vpc_project_v2.project_1.id
  region     = "ru-6"
  name       = "secgroup-1"
}
```

```terraform
# Default security group of the project
data "selectel_vpc_secgroup_v2" "secgroup_2" {
  project_id = selectel_vpc_project_v2.project_1.id
  region     = "ru-6"
  name       = "default"
}
```

## Schema

### Required

- `project_id` (String) Unique identifier of the associated project, for example, `a07abc12310546f1b9291ab3013a7d75`. Retrieved from the [selectel_vpc_project_v2](https://registry.terraform.io/providers/selectel/selectel/latest/docs/resources/vpc_project_v2) resource. Learn more about [Projects](https://docs.selectel.ru/en/control-panel-actions/projects/about-projects/).
- `region` (String) Pool where the security group is located, for example, `ru-6`. Learn more about available pools in [Product availability by location](https://docs.selectel.ru/en/infrastructure/product-availability-by-location/).

### Optional

- `description` (String) Description of the security group.
- `name` (String) Name of the security group.
- `secgroup_id` (String) Unique identifier of the security group. To get the security group ID, in the [Control panel](https://my.selectel.ru/vpc/), go to **Cloud Platform** ⟶ **Network** ⟶ the **Security Groups** tab ⟶ copy the ID of the required security group. As an alternative, you can use [OpenStack CLI](https://docs.selectel.ru/en/cloud-servers/tools/openstack-cli/) command `openstack security group list` and copy the `ID` field.
- `tags` (Set of String) Tags of the security group.

### Read-Only

- `all_tags` (Set of String) All tags of the security group.
- `id` (String) Unique identifier of the security group.
- `security_group_rules` (List of String) Unique identifiers of rules contained in the security group.
- `shared` (Boolean) Specifies if another project has been granted access to this group.
- `stateful` (Boolean) Specifies if the security group is stateful.
