# selectel_filestorage_availability_zones_v2

Provides a list of file storage availability zones of a pool in File Storage. For more information about file storage availability, see the [official Selectel documentation](https://docs.selectel.ru/en/infrastructure/product-availability-by-location/#file-storage).

## Example Usage

```terraform
data "selectel_filestorage_availability_zones_v2" "availability_zones_1" {
  project_id = selectel_vpc_project_v2.project_1.id
  region     = "ru-6"
}
```
