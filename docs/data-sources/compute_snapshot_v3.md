# selectel_compute_snapshot_v3

Provides a network volume snapshot in Cloud Servers. The data source filters snapshots by name, status, or source volume. Multiple matches cause an error unless `most_recent` is `true`. For more information about snapshots, see the [official Selectel documentation](https://docs.selectel.ru/en/cloud-servers/volumes/snapshots/).

## Example Usage

```terraform
data "selectel_compute_snapshot_v3" "snapshot_1" {
  project_id = selectel_vpc_project_v2.project_1.id
  region     = "ru-6"
  name       = "snapshot-1"
  volume_id  = selectel_compute_volume_v3.volume_1.id
}
```

## Schema

### Required

- `project_id` (String) Unique identifier of the associated project, for example, `a07abc12310546f1b9291ab3013a7d75`. The value cannot be empty or start or end with whitespace. You can retrieve the project ID from the [selectel_vpc_project_v2](https://registry.terraform.io/providers/selectel/selectel/latest/docs/resources/vpc_project_v2) resource. Learn more about [Projects](https://docs.selectel.ru/en/control-panel-actions/projects/about-projects/).
- `region` (String) Pool where the snapshot is located, for example, `ru-6`. The value cannot be empty or start or end with whitespace. Learn more about available pools in [Product availability by location](https://docs.selectel.ru/en/infrastructure/product-availability-by-location/#network-volumes).

### Optional

- `most_recent` (Boolean) Specifies if the most recent matching snapshot is selected. If omitted or `false`, multiple matches cause an error. Equal timestamps are resolved by the lexicographically smallest UUID.
- `name` (String) Exact snapshot name to search for. The minimum length is `1` character. If omitted, the data source returns the name of the selected snapshot. To get the snapshot name, use the [OpenStack CLI](https://docs.selectel.ru/en/cloud-servers/tools/openstack-cli/) command `openstack volume snapshot list` and copy the `Name` field.
- `status` (String) Exact API status to search for. The minimum length is `1` character. Use a lowercase value, for example, `available`. If omitted, the data source returns the status of the selected snapshot. To get the snapshot status, use the [OpenStack CLI](https://docs.selectel.ru/en/cloud-servers/tools/openstack-cli/) command `openstack volume snapshot list` and copy the `Status` field. Learn more about [snapshot statuses](https://docs.selectel.ru/en/cloud-servers/volumes/snapshots/#snapshot-statuses).
- `volume_id` (String) Unique identifier of the source network volume. The format is a lowercase UUID. The data source filters snapshots by this source volume. If omitted, it returns the source volume ID of the selected snapshot. You can retrieve the source volume ID with the [selectel_compute_volume_v3](https://registry.terraform.io/providers/selectel/selectel/latest/docs/data-sources/compute_volume_v3) data source.

### Read-Only

- `description` (String) Snapshot description.
- `id` (String) Unique identifier of the snapshot.
- `metadata` (Map of String) Snapshot metadata returned by the API.
- `size` (Number) Snapshot size in GB.
