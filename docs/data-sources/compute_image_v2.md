# selectel_compute_image_v2

Provides an image in Cloud Servers. The data source searches active images visible to the project and returns exactly one. A search that returns no images fails. A search that returns several images fails unless `most_recent` is `true`. For more information about images, see the [official Selectel documentation](https://docs.selectel.ru/en/cloud-servers/images/about-images/).

## Example Usage

```terraform
data "selectel_compute_image_v2" "image_1" {
  project_id  = selectel_vpc_project_v2.project_1.id
  region      = "ru-6"
  name        = "Ubuntu 24.04 LTS 64-bit"
  visibility  = "public"
  most_recent = true
}
```

## Schema

### Required

- `project_id` (String) Unique identifier of the associated project, for example, `a07abc12310546f1b9291ab3013a7d75`. The value cannot be empty or start or end with whitespace. You can retrieve the project ID from the [selectel_vpc_project_v2](https://registry.terraform.io/providers/selectel/selectel/latest/docs/resources/vpc_project_v2) resource. Learn more about [Projects](https://docs.selectel.ru/en/control-panel-actions/projects/about-projects/).
- `region` (String) Pool where the image is located, for example, `ru-6`. The value cannot be empty or start or end with whitespace. Learn more about available pools in [Product availability by location](https://docs.selectel.ru/en/infrastructure/product-availability-by-location/).

### Optional

- `container_format` (String) Container format of the image to search for. Available values are `bare`, `ovf`, `aki`, `ari`, `ami`, `ova`, `docker`, and `compressed`. If omitted, the data source returns the container format of the selected image. Learn more about [supported formats](https://docs.selectel.ru/en/cloud-servers/images/about-images/#own-images).
- `disk_format` (String) Disk format of the image to search for. Available values are `raw`, `vhd`, `vhdx`, `vmdk`, `vdi`, `iso`, `ploop`, `qcow2`, `aki`, `ari`, and `ami`. If omitted, the data source returns the disk format of the selected image. Learn more about [supported formats](https://docs.selectel.ru/en/cloud-servers/images/about-images/#own-images).
- `hidden` (Boolean) Specifies if the data source searches hidden images. If omitted or `false`, only images that are not hidden are found. If `true`, only hidden images are found. The data source returns whether the selected image is hidden.
- `member_status` (String) Status of the project access to shared images to search for. Available values are `accepted`, `pending`, `rejected`, and `all`. If omitted, only shared images with accepted access are found.
- `most_recent` (Boolean) Specifies if the data source selects the image with the latest `created_at` timestamp when several images match. Equal timestamps are resolved by the lexicographically smallest `id`. If omitted or `false`, the search must return exactly one image.
- `name` (String) Exact image name to search for. The minimum length is `1` character. This argument conflicts with `name_regex`. If omitted, the data source returns the name of the selected image. To get the image name, use the [OpenStack CLI](https://docs.selectel.ru/en/cloud-servers/tools/openstack-cli/) command `openstack image list` and copy the `Name` field.
- `name_regex` (String) Regular expression that the image name must match. The value must be a regular expression in the [RE2 syntax](https://github.com/google/re2/wiki/Syntax). This argument conflicts with `name`. The provider applies this filter to the images found by the other filters.
- `owner` (String) Unique identifier of the project that owns the image. The minimum length is `1` character. If omitted, the data source returns the owner of the selected image. To get the owner ID, use the [OpenStack CLI](https://docs.selectel.ru/en/cloud-servers/tools/openstack-cli/) command `openstack image list --long` and copy the `Project` field.
- `properties` (Map of String) Key-value pairs that the image properties must contain. The provider applies this filter to the images found by the other filters. The data source returns all properties of the selected image.
- `size_max` (Number) Maximum size of the image data in bytes. The minimum value is `0`.
- `size_min` (Number) Minimum size of the image data in bytes. The minimum value is `0`.
- `tag` (String) Tag that the image must have. The minimum length is `1` character. Use `tags` to search by several tags. Both arguments can be set.
- `tags` (Set of String) Set of tags that the image must have. The data source returns all tags of the selected image.
- `visibility` (String) Visibility of the image to search for. Available values are `public`, `private`, `shared`, and `community`. If omitted, the data source searches public images, images of the project, and shared images that the project accepted. Community images of other projects are found only with `visibility = "community"`. The data source returns the visibility of the selected image. Learn more about [image sharing](https://docs.selectel.ru/en/cloud-servers/images/transfer-image/#configure-access-to-image).
