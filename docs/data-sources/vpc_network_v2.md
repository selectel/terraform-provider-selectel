# selectel_vpc_network_v2

Provides a private network. For more information about private networks, see the [official Selectel documentation](https://docs.selectel.ru/en/cloud-servers/cloud-networks/private-networks-and-subnets/).

If you are upgrading from a version earlier than 9.0.0, follow the [upgrade guide](https://registry.terraform.io/providers/selectel/selectel/latest/docs/guides/upgrading_to_version_9) to migrate your resources from the OpenStack provider.

## Example Usage

```terraform
data "selectel_vpc_network_v2" "network_1" {
  project_id = selectel_vpc_project_v2.project_1.id
  region     = "ru-6"
  name       = "network-1"
}
```

- `status` (String) Status of the network. Available statuses are `ACTIVE`, `DOWN`, `BUILD`, or `ERROR`.
- `tags` (Set of String) Tags of the network.
