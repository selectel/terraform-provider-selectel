# selectel_compute_volume_v3

Provides a network volume in Cloud Servers. The data source finds the volume by `volume_id` or by any combination of `name`, `status`, and `metadata`. The search must return exactly one network volume. If `volume_id` and search criteria are not specified, there must be exactly one network volume in the specified project and pool. For more information about network volumes, see the [official Selectel documentation](https://docs.selectel.ru/en/cloud-servers/volumes/about-network-volumes/).

## Example Usage

```terraform
data "selectel_compute_volume_v3" "volume_1" {
  project_id = selectel_vpc_project_v2.project_1.id
  region     = "ru-6"
  volume_id  = selectel_compute_volume_v3.volume_1.id
}
```

## Schema

### Required

- `project_id` (String) Unique identifier of the associated project, for example, `a07abc12310546f1b9291ab3013a7d75`. The value cannot be empty or start or end with whitespace. You can retrieve the project ID from the [selectel_vpc_project_v2](https://registry.terraform.io/providers/selectel/selectel/latest/docs/resources/vpc_project_v2) resource. Learn more about [Projects](https://docs.selectel.ru/en/control-panel-actions/projects/about-projects/).
- `region` (String) Pool where the network volume is located, for example, `ru-6`. The value cannot be empty or start or end with whitespace. Learn more about available pools in [Product availability by location](https://docs.selectel.ru/en/infrastructure/product-availability-by-location/#network-volumes).

### Optional

- `metadata` (Map of String) Metadata subset to match. This argument conflicts with `volume_id`. The data source returns all metadata of the selected volume except the provider creation token.
- `name` (String) Exact network volume name to search for. The minimum length is `1` character. This argument conflicts with `volume_id`. If omitted, the data source returns the name of the selected volume. To get the volume name, use the [OpenStack CLI](https://docs.selectel.ru/en/cloud-servers/tools/openstack-cli/) command `openstack volume list` and copy the `Name` field.
- `status` (String) Exact API status to search for. The minimum length is `1` character. This argument conflicts with `volume_id`. If omitted, the data source returns the status of the selected volume. To get the volume status, use the [OpenStack CLI](https://docs.selectel.ru/en/cloud-servers/tools/openstack-cli/) command `openstack volume list` and copy the `Status` field.
- `volume_id` (String) Unique identifier of the network volume. The format is a lowercase UUID. This argument conflicts with `name`, `status`, and `metadata`. To get the volume ID, use the [OpenStack CLI](https://docs.selectel.ru/en/cloud-servers/tools/openstack-cli/) command `openstack volume list` and copy the `ID` field.
